# Loci v0.1.0

Windows x64 文件搜索服务和独立 Kite 插件包。

下载 `loci-kite-plugin.zip`，在支持 ZIP 导入及 Loci 文件搜索的 Kite 构建中直接导入，然后输入 `loci`，点击“安装服务（管理员授权）”，在安装向导中完成安装。服务安装到受保护的 `Program Files\Loci` 目录，之后 Kite 和插件保持普通权限。

仅支持目录导入的旧版 Kite 需要先解压插件包再导入目录。普通文件模式调用 Loci、操作完成后刷新状态等行为需要包含本次接入的 Kite 构建；旧版 Kite 不会自动获得这些宿主功能。

CLI 用户可直接下载安装 `loci-setup.exe`。插件包已经附带同一安装器，无需分别下载。两个文件均提供 `.sha256` 校验文件。

- 后台服务负责固定 NTFS 卷索引、USN 增量和 checkpoint；关闭 Kite 或退出插件不停止索引服务。
- 在插件中查看服务状态；导入新版插件后可点击“更新服务（管理员授权）”。
- 服务独立安装和卸载，卸载保留索引数据。
- 本地构建、协议和包导入测试已通过；真实管理员安装、全卷索引、升级和长期运行尚未完成验收，没有达到 Everything 性能的测量结论。
