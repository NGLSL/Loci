# Domain docs

本项目采用单一领域上下文（single-context）。

## 阅读入口

探索相关代码前，读取已有的：

- 根目录 `GLOSSARY.md`：项目术语及定义。
- `docs/adr/`：与本次工作相关的架构决策记录。

文件尚不存在时直接继续。由 `domain-modeling` 在实际厘清术语或决策时按需创建；初始化不生成空白术语表或 ADR。

## 使用规则

- 在规格、任务、设计、诊断和测试命名中使用术语表已有的词汇，保持同一概念的命名一致。
- 需要的概念尚未定义时，先核对当前代码的用语，再判断是否需要补充术语表。
- 与已有 ADR 冲突时，明确指出冲突的决策及重新讨论的理由。
